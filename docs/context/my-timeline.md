# My timeline (personal) — not the thesis PDF

**Why this file exists:** The schedule in the thesis (`ch3_planning`, Gantt, etc.) may show **institutional or illustrative** dates. This file is **your** source of truth for when *you* intend to finish work, with **buffers** before any hard deadline.

**Hard outer bound (from advisor context):** thesis submission **2026-09-20** — treat everything below as “must be green before that date minus my buffer.”

---

## Two layers (keep them separate)

| Layer | Where it lives | Purpose |
|--------|----------------|---------|
| **Public / thesis** | LaTeX Chapter 3 | What the document is allowed to claim; can lag or use official wording. |
| **Private / execution** | **This file** (+ calendar) | What you actually do week by week; **update every week**. |

When the thesis and reality diverge, **update the thesis once** during a dedicated “doc sync” session—do not let the PDF become your only planner.

## Weekly guardrail (5–15 minutes)

Every **fixed weekday** (circle one: ☐ Mon ☐ Fri ☐ Sun):

1. Open this file and set **Status** for any row that moved.  
2. Adjust **My target date** if something slipped—do not pretend the old date still holds.  
3. Copy the **next 7 days** into your calendar as concrete tasks (not vague “work on thesis”).  
4. If a slip consumes more than **3 days** of buffer on any milestone, **shrink scope** or **ask advisor**—do not only compress sleep.
